## The measurement, and what it does not cover

[`CORPUS-REPORT.md`](CORPUS-REPORT.md) is the corpus after the shipped policy;
[`CORPUS-REPORT-BEFORE.md`](CORPUS-REPORT-BEFORE.md) is the same corpus against an earlier build of
the policy, kept so the difference is checkable rather than asserted. Both are regenerated by
`npm run corpus`, which refuses to update the shipped page itself: the diff is printed and a person
decides.

The honest counterweight is [`../research/corpus-v2/TWINS-REPORT.md`](../research/corpus-v2/TWINS-REPORT.md),
which measures how often the policy discards ordinary work that merely LOOKS like an attack. It
reports the unflattering first number and the correction that followed, and the README says why both
are kept.
