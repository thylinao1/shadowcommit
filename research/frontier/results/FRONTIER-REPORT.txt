THE PARAMETER FRONTIER

distinct settings : 90
replays recorded  : 155

  65 settings were replayed more than once, on different cluster nodes.
  Every repeat returned identical counts. Nobody asked for a determinism check on the
  replay pipeline and this is one: the same policy over the same corpus gives the same
  numbers on a different machine, which is what every published figure here rests on.

== whether this run measured anything ==

A sweep where no point moves looks identical to a sweep whose substitution silently failed.
These two settings are absurd on purpose and MUST differ from the baseline.

  moved    tripwire:net-to-exec-window-off
  moved    tripwire:net-to-exec-window-huge

  The substitution takes effect, so a point that matches the baseline matches it for a reason.

== which axes anything reads ==

One absurd value per axis, on its own. A whole-file tripwire proves the substitution reaches
the FILE; this asks whether it reaches the AXIS.

CORRECTED 2026-08-31. This section used to conclude that an axis flat at its own extreme is
an axis nothing reads. That inference is wrong and it was wrong here. WINDOW_LINES is flat at
0 and at a million, and research/net-to-exec/window-blindness.mjs shows it changes the hunk
set on 4,005 of 10,240 corpus content blocks. It is read, it does change the windows, and not
one verdict moves. Flat means the CORPUS cannot see the axis. Whether anything reads it is a
different question and this sweep cannot answer it.
