# The 31 limitations: what is closed, what is next, what will not close

Written 31 August 2026 at `be5b1a9`. The source list is `PROJECT.md` section 6.

The first thing learned attacking this list is that the 31 are not 31 independent bugs. They
collapse into four root causes, and fixing a root closes several at once.

    A  the effect set is a diff of two END STATES        reads, transient state, cross-turn splits
    B  rules match LITERALS, not shapes                  generalisation gap, path-literal overfit
    C  the corpus is generated by TEMPLATES we wrote     label leakage, narrow intervals, blind spots
    D  disclosure hygiene                                excluded rows, n=1 families, incomplete evidence

## Closed, with the measurement

| Limitation | Root | What closed it | Measured |
|---|---|---|---|
| A read is not an effect | A | `rules/read-exposure.ts` | 0/32 to 32/32 held, 4 added holds on 48 benign |
| Composition rule never exercised | C | `probe-composed.jsonl` | 110 scenarios, 78 attacks over 32 shapes, 46 of 47 predictions held |
| Harness leaks the intent label | C | `replay-v2.mjs` | proven dormant, 0 of 8190 verdicts move; now one constant for every row |
| Intervals about 4x too narrow | D | `cluster-intervals.mjs` | honest intervals published, all three wider |
| Path-literal overfit, 3 detectors | B | rename ablation | renamed probe 6 misses to 2, zero cost |

Plus one defect the new corpus exposed and we fixed: **cross-effect gave different verdicts for
byte-identical effect sets in different arrival order**, and the attacker picks the order. A 16-pass
cap meant a chain written sink-first ran out of passes. Reversing your own writes was a bypass.

## Next, in dependency order

**1. Transient state inside a turn.** Root cause A, second half, and the read-exposure work opens
the door. A credential staged, used and deleted inside one turn produces zero effects, because the
effect set compares two end states. The read witness now proves the turn OPENED something; the
missing half is proving it CREATED something that no longer exists at settle. Start from
`capture.ts` and the witness, and expect the honest answer to be partial.

**2. Cross-turn attack splitting.** Root cause A, third. The turn is the unit of judgement, so an
attack split over two turns is never rejoined, distance does not help the defender, and the split
never expires. This is the largest remaining hole in the product's own thesis, because it is a
complete bypass rather than a gap. Allocated with an iterate-until-solved brief.

**3. The capability grant ships fully permissive.** `DEFAULT_CAPABILITY_GRANT` is `'**'`, `'*'`,
`MAX_SAFE_INTEGER`. It is enforced on every turn and by default permits everything. The cheapest
high-value item on this list: ship a sane default scope and measure the benign cost.

**4. The remaining unexercised rules.** Five of seventeen never decide a corpus row. Outbound has PR
52 waiting, composition now has a probe. Three left. The silent-rule gate pins the number so it
cannot silently grow. `governance-weakened` is the cautionary case: it reports 0 added false aborts
AND fires 0 times on all 8,190 rows, so the zero is an absence, not a result.

**5. Two known scanner boundaries an attacker can cross for free.** `MAX_LINES = 5000` in
`cross-effect.ts` and `net-to-exec.ts`: moving a payload one line down in a created file turns a
discard into a commit. Same class as the pass-cap bypass just fixed, and the fix shape is the same:
find the bound that is actually load-bearing and delete the one that is not.

**6. Payloads under vendored paths are never scanned.** `isScannable` rejects `VENDORED_PATH`
before any content rule runs, across nine directory names, four of which are caught on neither
create nor modify.

**7. The remaining path-literal detectors.** Root cause B. Allocated. The rename gate now
fails the build on regression, so this can only improve.

## What will not close, and the fix is to bound it precisely

These are properties of the design. Claiming to have fixed them would be the overstatement this
project has spent days removing.

- **The policy never reads what code does.** It matches lines and before/after pairs. One
  authorization defect stated six ways commits four times. Fixing this means building a semantic
  analyser, which is a different product.
- **The semantic control is a dictionary, not comprehension.** It held 80 of 81 corpus semantic
  attacks and zero of them by understanding the change.
- **The corpus miss rate does not predict the blind rate.** 3.64 percent against 47.9 percent at
  baseline on a blind set. This is epistemics, not a bug. The honest response is to publish the
  blind number, which we now do.
- **The label is close to a function of the generator template.** Fixable only by importing attacks
  we did not write, which is a corpus programme rather than a fix.
- **TLS is opaque to the hold control.** A CONNECT tunnel has no method and no request path to
  classify. Partially addressable by holding tunnels to non-allowlisted destinations, at a cost
  nobody has measured.

## The rule this list taught

A number measured on data the thing was built from is not a result. Every entry above states what it
does NOT prove, next to what it does, because three separate times this week a zero turned out to be
an absence rather than a safety property.
